## 1. Что такое система счисления
**Система счисления** — способ записи чисел с помощью определённого набора символов и правил их использования. В позиционной системе значение цифры зависит от её положения в записи числа.

Основание системы счисления показывает, сколько различных цифр используется. Для основания `q` допустимы цифры от `0` до `q − 1`.

## 2. Основные системы счисления

| Система | Основание | Используемые цифры | Пример |
|---|---:|---|---|
| Десятичная | 10 | 0–9 | `245₁₀` |
| Двоичная | 2 | 0, 1 | `1011₂` |
| Восьмеричная | 8 | 0–7 | `37₈` |
| Шестнадцатеричная | 16 | 0–9, A–F | `2F₁₆` |

В шестнадцатеричной системе буквы обозначают значения: `A = 10`, `B = 11`, `C = 12`, `D = 13`, `E = 14`, `F = 15`.

## 3. Как читать позиционную запись
Каждый разряд соответствует степени основания. Например:

`345₁₀ = 3 · 10² + 4 · 10¹ + 5 · 10⁰ = 345`.

Аналогично:

`1011₂ = 1 · 2³ + 0 · 2² + 1 · 2¹ + 1 · 2⁰ = 11₁₀`.

## 4. Перевод целого числа из системы с основанием q в десятичную
Умножьте каждую цифру числа на соответствующую степень основания, начиная справа со степени ноль, а затем сложите результаты.

## 5. Перевод целого десятичного числа в систему с основанием q
Последовательно делите число на `q`, пока частное не станет равно нулю. Записывайте остатки. Результат читается снизу вверх — от последнего остатка к первому.

## 6. Быстрый перевод между двоичной и восьмеричной/шестнадцатеричной системами
- Для перевода из двоичной в восьмеричную разбейте запись справа налево на группы по **3 бита**.
- Для перевода из двоичной в шестнадцатеричную разбейте запись справа налево на группы по **4 бита**.
- Если в самой левой группе не хватает разрядов, дополните её нулями слева.

Это удобно, потому что `8 = 2³`, а `16 = 2⁴`.

## Важно помнить
- Основание системы всегда больше любой цифры, используемой в этой системе.
- Остатки при переводе из десятичной системы читаются в обратном порядке.
- При группировке двоичных разрядов нули добавляют слева, а не справа.
- Индекс у числа (например, `₂` или `₁₆`) указывает основание системы счисления.
