# Глоссарий

1. **Система счисления** — способ записи чисел с помощью определённого набора символов и правил. Система задаёт, как цифры образуют числовые значения.
2. **Основание системы счисления** — количество различных цифр, используемых в позиционной системе. Например, у двоичной системы основание равно 2.
3. **Цифра** — символ, используемый для записи числа. В системе с основанием `q` допустимы цифры от `0` до `q − 1`.
4. **Позиционная система счисления** — система, в которой значение цифры зависит от её позиции в записи числа. Примеры: десятичная, двоичная и шестнадцатеричная системы.
5. **Разряд** — позиция цифры в записи числа. Каждому разряду целой части соответствует определённая степень основания.
6. **Вес разряда** — значение, равное основанию системы счисления, возведённому в степень номера разряда. В целой части отсчёт обычно начинается справа с нулевого разряда.
7. **Двоичная система счисления** — позиционная система с основанием 2, использующая только цифры 0 и 1. Она широко применяется для представления данных в компьютерах.
8. **Восьмеричная система счисления** — позиционная система с основанием 8, использующая цифры от 0 до 7. Одна её цифра соответствует группе из трёх двоичных разрядов.
9. **Шестнадцатеричная система счисления** — позиционная система с основанием 16, использующая цифры 0–9 и буквы A–F. Одна её цифра соответствует четырём двоичным разрядам.
10. **Бит** — двоичный разряд, который может принимать одно из двух значений: 0 или 1. Бит является базовой единицей количества информации.
11. **Позиционная запись числа** — представление числа как суммы произведений цифр на веса соответствующих разрядов. Например, `23₈ = 2 · 8¹ + 3 · 8⁰`.
